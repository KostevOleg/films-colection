About FilmApp

FilmApp is a signal-based Angular movie catalog built as a learning project.

Features

  • Film catalog from mock data
  • Search by film title
  • Filter by genre
  • Filter by favorite status
  • Add and remove films from favorites
  • Film details page with full information
  • Simple pagination with Angular Signals
  • Breadcrumb navigation
  • Custom autofocus directive for the search field
  • Custom duration pipe for film runtime
